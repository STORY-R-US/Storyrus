# Base de desenvolvimento Story R Us

Esta é a base única da aplicação. Mantenha a estrutura `backend/`, `apps/web/`
e `apps/mobile/`. Novas alterações devem partir desta pasta.

Leia `README.md` e `docs/BASE_INICIAL.md` para a configuração inicial.
Use os testes de cada aplicação e a CI existente para validar mudanças.
Guarde chaves e senhas nas variáveis de ambiente; os arquivos `.env` reais
e os dados de produção não devem ser versionados.
